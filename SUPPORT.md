# Support

**handle** is pre-alpha and spec-first. See [`BUILD_SPEC.md`](./BUILD_SPEC.md).

| Need | Where |
|---|---|
| Bugs / features | [GitHub Issues](https://github.com/SM260845/handle/issues) |
| Design / Q&A | [GitHub Discussions](https://github.com/SM260845/handle/discussions) |
| Security | [`SECURITY.md`](./SECURITY.md) — private advisory, not a public issue |
| Spec / stages | [`BUILD_SPEC.md`](./BUILD_SPEC.md) and the `stage:N` issues |

When filing a bug, include: OS, Node version (`node -v`), `pnpm -v`, the command you ran, and the full error. For anything involving Claim / mail / VMs, also include the receipt id if you have one (never paste secrets).
